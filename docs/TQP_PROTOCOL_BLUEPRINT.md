## 1. 项目概述

### 1.1 目标

开发一套完全私有的代理协议 **TQP (TianQue Protocol)**，满足以下要求：

| 目标 | 描述 | 优先级 |
|------|------|--------|
| **无特征** | GFW 无法通过 DPI 识别 | P0 |
| **轻量快速** | 最小化握手延迟，高吞吐 | P0 |
| **完整控制** | 后端认识、面板能管理、客户端能用 | P0 |
| **流量统计** | 准确的用户流量上报 | P1 |
| **易于维护** | 代码清晰，便于迭代 | P2 |

### 1.2 现有资源 ⚠️ 关键架构澄清

**关键发现**:

| 组件 | 内核 | 是否可扩展 | 说明 |
|------|------|------------|------|
| **V2bX 后端** | sing-box (本地 fork: `sing-box_mod`) | ✅ 可以 | 需要在 sing-box 中添加 TQP inbound |
| **mihomo 客户端** | mihomo (Clash Meta) | ✅ 可以 | 需要 Fork 添加 TQP outbound |
| **Shadowrocket** | 闭源私有 | ❌ **无法** | 不开放第三方协议扩展 |

**小火箭兼容性问题**:
- Shadowrocket 是闭源商业软件
- 不提供插件 API 或自定义协议接口
- **无法支持 TQP 协议**（除非官方主动实现）
- 替代方案：引导用户使用支持 TQP 的客户端 (Stash, Clash Verge 等)

### 1.3 为什么不直接用现有协议？

| 协议 | 问题 |
|------|------|
| VMess | 特征明显，长度字段可识别 |
| VLESS | 被重点关注，主动探测可识别 |
| Trojan | SNI 暴露，密码认证特征 |
| Shadowsocks | 2022 虽好但仍有熵特征 |
| Hysteria2 | QUIC 被针对性封锁 |
| TLS-in-TLS | 已被识别（流量重放检测） |

## 3. GFW 检测机制分析

### 3.1 已知检测方法及规避策略

| 检测方法 | 技术细节 | TQP 规避策略 |
|----------|----------|--------------|
| **熵分析** | 检测数据随机性过高（纯加密数据熵≈8） | 添加结构化 padding，降低熵值到 6-7 |
| **包长分布** | 统计包长度模式识别代理流量 | 随机 padding，打破固定模式 |
| **TLS 指纹** | JA3/JA4 识别非浏览器客户端 | 使用 uTLS 模拟 Chrome 指纹 |
| **SNI 黑名单** | 检查 TLS ClientHello 的 SNI | 使用白名单域名（microsoft.com 等）|
| **主动探测** | 向可疑服务器发探针 | 返回真实网站内容 |
| **流量重放** | 检测相同数据多次发送 | 每个包 nonce 唯一，重放无效 |
| **时序分析** | 检测请求-响应时间模式 | 添加随机延迟抖动（可选） |
| **TLS-in-TLS** | 检测嵌套 TLS 握手 | ⚠️ **不使用此方案** |

### 3.2 关键洞察

```
GFW 检测逻辑：
1. 快速通道：白名单协议/IP 直接放行
2. 黑名单：已知代理服务器 IP 直接封
3. 灰色地带：DPI 分析 → 主动探测 → 决定

TQP 目标：
让流量进入"快速通道"，看起来像普通 HTTPS
```

## 4. 协议设计原则

### 4.1 核心原则

| 原则 | 描述 | 实现方式 |
|------|------|----------|
| **最小化特征** | 流量与正常 HTTPS 无法区分 | 复用 TLS，不加额外头部 |
| **零 RTT 优化** | 减少握手往返 | 一次性认证，后续无握手 |
| **流式处理** | 数据到即处理，不缓存 | 分块加密而非整包加密 |
| **协议版本化** | 支持未来升级 | 协议头包含版本号 |
| **降级友好** | 不支持时返回正常页面 | 伪装成普通网站 |

### 4.2 协议分层设计

```
┌─────────────────────────────────────────────┐
│ Layer 4: 应用数据                           │
│ • 实际的代理请求/响应                        │
├─────────────────────────────────────────────┤
│ Layer 3: TQP 帧（加密 + 认证）               │
│ • 用户 UUID 验证                             │
│ • ChaCha20-Poly1305 加密                     │
│ • 抗重放 nonce                              │
├─────────────────────────────────────────────┤
│ Layer 2: HTTP/2 多路复用（可选）             │
│ • 如果使用 gRPC 传输                         │
├─────────────────────────────────────────────┤
│ Layer 1: TLS 1.3                            │
│ • 标准握手                                   │
│ • uTLS 指纹伪装                              │
│ • ALPN: h2 或 http/1.1                       │
├─────────────────────────────────────────────┤
│ Layer 0: TCP                                │
│ • 标准 TCP 连接                              │
└─────────────────────────────────────────────┘
```

### 4.3 与 REALITY/VLESS 的区别

| 特性 | VLESS+REALITY | TQP |
|------|---------------|-----|
| 握手 | 需要额外握手 | 复用 TLS，无额外握手 |
| 认证 | UUID 明文（在 TLS 内） | UUID 哈希 + 时间戳 |
| 公开程度 | 开源，特征已知 | 私有，无公开特征 |
| 指纹 | 固定模式 | 动态随机化 |

### 5.2 帧格式设计

#### 5.2.1 认证帧 (Auth Frame) - 仅首包

```
+------+------+------------+------------------+
| Ver  | Cmd  | Timestamp  | Auth Hash        |
| 1B   | 1B   | 8B         | 32B              |
+------+------+------------+------------------+
| 0x01 | 0x01 | Unix时间戳  | HMAC-SHA256      |
+------+------+------------+------------------+
       42 字节固定长度

Ver: 协议版本 (当前 0x01)
Cmd: 命令类型
     0x01 = 认证请求
     0x02 = 心跳
     0xFF = 关闭连接

Auth Hash 计算方式:
  auth_hash = HMAC-SHA256(
    key = UUID,
    message = timestamp || server_host || server_port
  )
```

#### 5.2.2 数据帧 (Data Frame)

```
方案 A: 极简方案（无额外头部，最小开销）
+----------------------------------------------------+
| Encrypted Payload (ChaCha20-Poly1305)              |
| N 字节（加密后比原文多 16 字节 auth tag）             |
+----------------------------------------------------+

方案 B: 带长度头（支持分包重组）
+--------+----------------------------------------------------+
| Length | Encrypted Payload                                  |
| 2B     | N 字节                                              |
+--------+----------------------------------------------------+

推荐：方案 A（TCP 流本身保证顺序，无需长度头）
```

#### 5.2.3 目标地址编码

```
首个数据帧需包含目标地址:

+------+------+-------------------+------+
| Type | Len  | Address           | Port |
| 1B   | 1B   | Variable          | 2B   |
+------+------+-------------------+------+

Type:
  0x01 = IPv4
  0x03 = 域名
  0x04 = IPv6

示例: 连接 google.com:443
  03 0A 67 6F 6F 67 6C 65 2E 63 6F 6D 01 BB
  │  │  │                              │
  │  │  └── "google.com" UTF-8         └── 443 (big-endian)
  │  └── 长度 10
  └── 类型: 域名
```

### 5.3 加密方案

```go
// 密钥派生
func deriveKey(uuid string, salt []byte) []byte {
    // HKDF 派生
    return hkdf.Extract(sha256.New, []byte(uuid), salt)
}

// 加密
// 使用 ChaCha20-Poly1305 (AEAD)
// - 比 AES-GCM 在无硬件加速时更快
// - 安全性等价
// - 每个包使用递增 nonce

type TQPCipher struct {
    aead   cipher.AEAD
    nonce  uint64  // 递增，防重放
    key    []byte
}

func (c *TQPCipher) Encrypt(plaintext []byte) []byte {
    nonce := make([]byte, 12)
    binary.BigEndian.PutUint64(nonce[4:], c.nonce)
    c.nonce++
    
    return c.aead.Seal(nonce, nonce, plaintext, nil)
}

func (c *TQPCipher) Decrypt(ciphertext []byte) ([]byte, error) {
    if len(ciphertext) < 12+16 {
        return nil, errors.New("ciphertext too short")
    }
    nonce := ciphertext[:12]
    
    return c.aead.Open(nil, nonce, ciphertext[12:], nil)
}
```

### 7.2 流量统计时机

```go
// 在数据转发时统计
func (h *TQPHandler) relay(client, target net.Conn, userUUID string) {
    // 上行：客户端 → 目标
    go func() {
        buf := make([]byte, 32*1024)
        for {
            n, err := client.Read(buf)
            if err != nil {
                break
            }
            // 解密
            data, _ := h.cipher.Decrypt(buf[:n])
            
            // ⭐ 统计上行流量 (解密后的实际大小)
            h.counter.AddUpload(userUUID, int64(len(data)))
            
            target.Write(data)
        }
    }()
    
    // 下行：目标 → 客户端
    go func() {
        buf := make([]byte, 32*1024)
        for {
            n, err := target.Read(buf)
            if err != nil {
                break
            }
            
            // ⭐ 统计下行流量 (加密前的实际大小)
            h.counter.AddDownload(userUUID, int64(n))
            
            // 加密
            encrypted := h.cipher.Encrypt(buf[:n])
            client.Write(encrypted)
        }
    }()
}
```

### 12.4 TQP Outbound 实现模板

```go
// mihomo/adapter/outbound/tqp.go (新文件)
package outbound

import (
    "context"
    "net"
    
    C "github.com/metacubex/mihomo/constant"
    "github.com/metacubex/mihomo/transport/tqp"  // 新的传输层
)

// TQP 协议适配器
type TQP struct {
    *Base
    client *tqp.Client
    option *TQPOption
}

// TQP 配置选项 (对应 YAML 配置)
type TQPOption struct {
    BasicOption
    Name           string `proxy:"name"`
    Server         string `proxy:"server"`
    Port           int    `proxy:"port"`
    Password       string `proxy:"password"`       // UUID
    TLS            bool   `proxy:"tls,omitempty"`
    ServerName     string `proxy:"servername,omitempty"`
    Fingerprint    string `proxy:"client-fingerprint,omitempty"`
    SkipCertVerify bool   `proxy:"skip-cert-verify,omitempty"`
    UDP            bool   `proxy:"udp,omitempty"`
}

// DialContext 建立 TQP 连接
func (t *TQP) DialContext(ctx context.Context, metadata *C.Metadata) (C.Conn, error) {
    // 1. 建立 TCP 连接
    c, err := t.dialer.DialContext(ctx, "tcp", t.addr)
    if err != nil {
        return nil, err
    }
    
    // 2. TLS 握手 (使用 uTLS 指纹)
    c, err = t.streamTLSConn(ctx, c)
    if err != nil {
        c.Close()
        return nil, err
    }
    
    // 3. TQP 握手 & 认证
    c, err = t.client.StreamConn(c, metadata)
    if err != nil {
        c.Close()
        return nil, err
    }
    
    return NewConn(c, t), nil
}

// 构造函数
func NewTQP(option TQPOption) (*TQP, error) {
    addr := net.JoinHostPort(option.Server, strconv.Itoa(option.Port))
    
    client, err := tqp.NewClient(option.Password)
    if err != nil {
        return nil, err
    }
    
    return &TQP{
        Base: &Base{
            name: option.Name,
            addr: addr,
            tp:   C.TQP,  // 新的协议类型
            udp:  option.UDP,
        },
        client: client,
        option: &option,
    }, nil
}
```
